# UI20: Mobile: Scoped Animal Notifications & Filters in Notifications Module

## Scope & Implementation Notes

1. **Animal Profile Notification Scoping**:
   - Tapping the notification bell in `CattleDetailScreen.tsx` (`header-btn-remind` or workspace reminder action) passes animal context (`id`, `tagNumber`, `name`, `group`) to `openNotifications`.
   - `NotificationSheet.tsx` displays a scoped animal banner when opened with animal context, offering a 1-tap clear button `(✕)` to view all notifications.
   - `InboxTab.tsx` filters notifications for the specified animal (via link, data payload, or tag matching).
   - `UpcomingTab.tsx` filters upcoming reminders/schedules for the specified animal.
   - `NewTab.tsx` pre-selects the animal by default in `selectedAnimals`.

2. **Notifications Module Filters**:
   - Filter bar with quick-filter pills and a comprehensive filter sheet:
     - Event Category / Type (Health & Safety, Reproduction, Operational, Financial, Inventory).
     - Cattle Group (Milking, Dry, Heifer, Bull, Calf, Sick).
     - Animal Picker (filter by any animal).
     - Status (All, Unread).
   - Clear All and individual filter chip dismissals with empty-filter states and 1-tap reset buttons.

3. **Design & Verification**:
   - Strictly conforms to ADR-007 (zero drop shadows, 1px border separation, tokens only).
   - Bilingual messages in English and Bengali with full placeholder parity.
   - Type-check (`tsc`), ESLint, node tests (`353 tests`), and Jest unit tests (`NotificationSheet.test.tsx`) all green.
