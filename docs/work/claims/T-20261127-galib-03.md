# T-20261127-galib-03: Mobile App Icon and Web Favicon Branding

## Goal
Generate mobile app icon assets (Expo `icon.png`, `adaptive-icon.png`, `favicon.png`) and website tab favicons (`apps/web/app/favicon.ico`, `apps/admin/app/favicon.ico`, etc.) using the user-provided brand "R" mascot cow silhouette icon.

## Scope
1. Process the 1024x1024 high-res user image into:
   - `apps/mobile/assets/icon.png` (1024x1024)
   - `apps/mobile/assets/adaptive-icon.png` (1024x1024 centered within safe zone)
   - `apps/mobile/assets/favicon.png` (48x48 / 192x192)
2. Configure `apps/mobile/app.json` with icon references.
3. Replace default Create Next App / React favicon in `apps/web/app/favicon.ico` and `apps/admin/app/favicon.ico`.
4. Verify build, lint, and formatting.
