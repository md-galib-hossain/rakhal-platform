## Scope & Implementation Notes

Ensure the "Done" button sticks permanently to the bottom and inner animal list scrolls independently in the notifications filter animal picker modal:
1. Set `scrollable={false}` on `SheetModal` for `notif-animal-picker-modal` and `notif-filter-sheet`.
2. Header and Search bar remain pinned at the top.
3. Animal list uses `<ScrollView style={{ flex: 1 }}>` with independent smooth scrolling between the search bar and the Done button.
4. "Done" action button container stays pinned / fixed to the bottom (`borderTopWidth: 1, borderColor: colors.border`).
5. Filter sheet action buttons (Reset & Apply) container is also pinned permanently to the bottom outside the filter sections ScrollView.
6. Maintained strict zero drop shadows rule (ADR-007).
