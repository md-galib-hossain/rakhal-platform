# UI17: Animal Workspace: Prevent Full Layout Scroll When Scrolling at End of Nested Sections

## Objectives
1. Prevent the outer screen ScrollView from scrolling when user is scrolling inside "Recent Events" and "Next Up & Reminders" inner ScrollViews and reaches content boundaries.
2. In `OverviewTab.tsx`, add touch and scroll drag callbacks (`onTouchStart`, `onTouchEnd`, `onTouchCancel`, `onScrollBeginDrag`, `onScrollEndDrag`, `onMomentumScrollBegin`, `onMomentumScrollEnd`), plus `overScrollMode="never"` and `bounces={false}`.
3. In `CattleDetailScreen.tsx`, control `scrollEnabled` on the outer ScrollView so it locks while the user is actively interacting with the inner sections.
4. Verify on live emulator and unit tests.
