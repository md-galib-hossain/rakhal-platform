# UI14: Animal Profile Consistency: Fixed Height Section Containers with Internal Scroll

## Objectives
1. Fix section container height differences caused by varying data quantities across animals.
2. Provide a fixed, well-fit height for content sections (`Recent Events`, `Next Up & Reminders`, etc.) on the Animal Profile Overview tab.
3. When data exceeds the fixed container height, enable smooth internal scrolling (`nestedScrollEnabled`) inside the section so that the overall screen height remains predictable, compact, and consistent across all animals.
4. When data is empty, render the centered structured empty state within the exact same fixed container height.
5. Verify on live emulator across animals (Lokkhi with 5 events & 5 reminders vs COW-DEV-001 with 1 event & 0 reminders).

## Completion Notes
- Fixed `card-recent-events` container to `height: 230` with inner `ScrollView nestedScrollEnabled` and centered empty state fallback.
- Fixed `card-next-up` container to `height: 270` with inner `ScrollView nestedScrollEnabled` and centered calendar empty state fallback.
- Added `nestedScrollEnabled` on `CattleDetailScreen.tsx` parent `ScrollView` for smooth Android gesture coordination.
- Zero drop shadows (ADR-007 compliant).
- All unit, node, and jest tests green (353 node tests passed, 570 jest tests passed, tsc clean, eslint clean).
- Verified on live emulator on Lokkhi, COW-DEV-001, and Shundori. Section heights remain completely stable and predictable without expanding the whole page.
