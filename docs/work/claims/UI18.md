# UI18: Animal Workspace: Interactive Ancestry Tree on Mobile (FamilyTab)

## Objectives
1. Implement the interactive Ancestry Tree in `FamilyTab.tsx` matching the web design (orthogonally connected genealogical tree with Parents, Self & Siblings, Offspring).
2. Create `AncestryTreeView.tsx` with:
   - Floating zoom & view controls (Zoom in, Zoom out, Zoom level percentage, Reset, Fit View).
   - Pan and zoom support (touch pan and button zoom with parent scroll isolation).
   - Dotted grid canvas background.
   - SVG orthogonal connecting branch lines using `react-native-svg`.
   - Node cards for Mother, Father, Self, Siblings, Offspring with relation pills, gender badges, farm name, and navigation on tap.
   - Generous height (`500dp`) and level vertical rhythm (`140dp`) ensuring all 3 tree rows (Parents, Self & Siblings, Offspring) fit cleanly in the canvas without clipping.
3. Expanded `Next Up & Reminders` card height in `OverviewTab.tsx` to `540dp` so at least 3 full reminder data rows (with title, time elapsed tag, date, and Snooze/Skip/Record action buttons) fit comfortably without being cut off.
4. Keep ADR-007 compliance (zero drop shadows, 1px borders, tokens only).
5. Verify with unit tests, TypeScript, ESLint, and live Android emulator.
