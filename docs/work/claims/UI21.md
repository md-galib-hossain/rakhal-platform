## Scope & Implementation Notes

Simplify the congested and redundant filter/category UI in the Notifications module (`NotificationSheet.tsx`, `InboxTab.tsx`, `UpcomingTab.tsx`):
1. **Eliminate 3x cow tag repetition and clutter in animal scope**:
   - Replaced redundant `notif-scoped-banner` text and double badges with ONE clean, compact context bar:
     Left: Cow icon (`CowIcon`) + `#{scopedAnimal.tagNumber}` (bold, primary) + `· {scopedAnimal.name}`.
     Right: Clear button (`testID="notif-clear-animal-scope"`) with label + `✕`.
   - Removed duplicate `filter-chip-animal` chip from active filter row (the scope bar is the clear indicator).
   - Excluded `scopedAnimal` from the `Filters` trigger button count (`offScreenFilterCount`).
2. **Streamline Category and Filter Rows**:
   - Removed redundant multi-line "Active filter chips" row below the category carousel.
   - Streamlined Category pills carousel + `Filters` trigger into a single, compact 32dp horizontal row.
   - Added inline `filter-chip-group` dismissible badge when an off-screen group filter is active.
   - Compacted `[All | Unread]` subheader in `InboxTab` and range selector in `UpcomingTab` with touch targets >= 48dp (using hitSlop).
   - Lazily rendered `NotificationSheet` in `NotificationContext.tsx` only when `isOpen` is true.
3. **Strict adherence to ADR-007**:
   - Zero drop shadows (`no-shadows.test.ts` passed).
   - 1px border separation, theme tokens only, touch targets >= 48dp.
4. **Verification**:
   - Jest tests in `NotificationSheet.test.tsx` passing (6/6).
   - Full mobile test suite passing (52/52 suites, 578/578 tests).
   - Node tests (357/357), token drift, messages parity, and `no-shadows` passing.
   - Typecheck (`tsc --noEmit`), ESLint, and `work.mjs check` passing (0 errors, 0 warnings).
