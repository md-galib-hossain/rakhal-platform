## Scope & Implementation Notes

Implement consistent mobile design and simple uncongested layout in Notifications module:
1. **Consistent Icon-Only Filter Button**:
   - Replaced the wide "Filters" text button with an icon-only square button (`<FilterIcon size={18} />`) matching `CattleList` and `MilkScreen`.
   - Built reusable `NotificationFilterTrigger.tsx` (`36x36`, 8dp hitSlop for 52x52dp touch target, `testID="notif-filter-trigger"`).
   - When active filters exist (`activeFilterCount > 0`), displays a circular count badge at top-right (`top: 4, right: 4`, minWidth: 16, height: 16, primary background).
   - Removed the text label "Filters" completely from the trigger button.
2. **Animal Multi-Selection without Post-Filter Chips**:
   - Supported multi-selecting animals in the Animal Picker modal (`selectedAnimals: AnimalScope[]`).
   - Tapping an animal toggles selection with an instant checkmark indicator (`CheckIcon`).
   - Added a "Done" button (`notif-animal-picker-done`) to confirm selection and return to the filter sheet modal.
   - Inside Section 3 of the filter sheet: displays summary count (`{count} animals selected`) or tag (`#COW-001`) with clear button (`notif-filter-clear-animal`).
   - Crucial Rule Honored: When the filter sheet closes, individual animal chips and scoped banners are NOT rendered on the main notification screen. The filter icon button's badge counter is the sole, clean indicator on the main screen.
3. **Clean Single-Row Filter / Subheader**:
   - In `InboxTab`: unified into ONE subheader row (`height: 32`):
     - Left: `[ All | Unread ]` segmented control (`height: 32`).
     - Right: `[ Mark all read ]` (when unread > 0) + `FilterIcon` square button (`testID="notif-filter-trigger"`).
   - In `UpcomingTab`: unified into ONE subheader row (`height: 32`):
     - Left: `[ Today | Next 7d | Next 14d ]` segmented control (`height: 32`).
     - Right: `FilterIcon` square button (`testID="notif-filter-trigger"`).
   - Moved Event Category selection inside the Filter Bottom Sheet Modal (Section 1: Category, Section 2: Group, Section 3: Animals).
   - The main screen now has:
     - Header (`Notifications` + settings + close)
     - Main tabs (`Inbox | Upcoming | New`)
     - ONE single subheader row
     - Immediate notification list with zero congestion!
4. **Strict ADR-007 Compliance**:
   - Zero drop shadows, 1px border separation, theme tokens only, touch targets >= 48dp.
