# UI12: Animal Workspace Event Actions (Heat, Service, Weight, Illness, etc.)

## Objectives
1. **Interactive Event Recording**:
   - Provide clean modal forms for recording animal events:
     - Heat Observation (`HEAT`): detection method, symptoms (standing heat, mucus, mounting, restlessness), notes.
     - AI / Service (`BREEDING`): breeding method (AI, Natural, Embryo), semen source, sire name/code, inseminator, service cost, notes.
     - Pregnancy Check (`PREG_CHECK`): result (Pregnant, Not Pregnant, Suspected), diagnosis method, gestation days / months pregnant, expected calving date, notes.
     - Weight Measurement (`WEIGHT`): weight in kg, notes.
     - Body Condition Score (`BCS`): score (1-5 in 0.25 steps), notes.
     - Calving (`CALVING`): ease, calf count, calf gender, calf tag number, birth weight, notes.
     - Sickness / Illness (`ILLNESS`): condition, severity, symptoms, notes.
     - General Note (`NOTE`): note text.
2. **Direct Quick Actions**:
   - Wire `+ Heat` on reproduction card -> opens Heat form directly.
   - Wire `+ AI / service` on reproduction card -> opens Service form directly.
   - Wire `+ Weigh` on growth card -> opens Weight form directly.
   - Wire `+ Report sickness` on health card -> opens Illness form directly.
   - Wire `+ Record event` (floating bottom button & timeline) -> opens category picker sheet; selecting an event opens its form.
3. **Backend Integration**:
   - `POST /api/v1/cattle/:id/events` with `Idempotency-Key` and authenticated client.
   - Handle loading, validation errors, and API responses.
   - Invalidate & reload animal detail on success to immediately reflect new timeline entry and updated herd status/metrics.
4. **UX & Design System**:
   - Strictly ADR-007 compliant (no drop shadows, 1px border separation, token fills).
   - Touch targets >= 48dp, full bilingual support in `messages.ts` (en and bn).
   - Sheet modal with scrollable content, clear labels, keyboard dismiss, and sticky submit/cancel footer.
5. **Testing**:
   - Unit and screen tests covering event form submission, error handling, quick action launches, and i18n parity.
   - Verification on Android emulator with real NestJS backend and live PostgreSQL database.
