# T-20261127-galib-02: Mobile Animal List Screen & Card Redesign (Inspiration UI)

## Scope
Redesign mobile animal list screen and cards (`apps/mobile/src/cattle/`) based on ChatGPT inspiration design:
- Top Header & Stats Grid: Total Animals, Avg Herd AQR, Breeding Ready, Active Milking in clean rounded cards.
- Horizontal Category Pills: All [N], Cows [N], Heifers [N], Calves [N].
- Redesigned CattleCard:
  - Circular avatar with status indicator dot.
  - Name with gender glyph (♀ / ♂), Farm tag ID.
  - Glanceable horizontal metrics: Age (📅), Weight (⚖️), Shed (📍).
  - Prominent AQR Score Box (e.g. AQR 71 /100) with color tint.
  - Twin status pills: [ 💚 Healthy ] and [ 💧 Milking ].
  - Expandable in-card accordion:
    - Quick tabs: Overview, Health, Milk, Reproduction.
    - 4 grid tiles: Last Milk Yield, Next Event, Lactation stage, Production Trend.
    - "View Full Details →" link.
- Strict ADR-007 compliance (zero shadows).
- Bilingual i18n parity in `messages.ts`.
- Zero breaking backend or web changes.
