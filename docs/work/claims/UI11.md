# UI11: Mobile Add Animal 2-Step Flow and Sheet Modal

## Objectives
1. **AddAnimalModal**: Implement a 2-step Add Animal modal for mobile:
   - Step 1: Basic Info (Cow image, Cow name, Tag ID, Breed, Gender, Shed, Animal group, Date of birth, derived category preview) + Additional Info (Mother, Father, Source, Color, Weight, Notes).
   - Step 2: Her history (optional) / His history (optional) matching web intake history logic (Calving history, Milking history, Breeding/AI record, Pregnancy status with months/due date, Vaccination, and dynamic event setup preview).
2. **Design & UX Consistency**:
   - Zero drop shadows (ADR-007).
   - Clean 1px border separation, comfortable touch targets (>= 48dp).
   - Proper modal height capping using `SheetModal` with pinned header, scrollable body, and pinned footer action buttons.
   - Proper input padding to avoid border clipping.
3. **Integration**:
   - Wire "+ Add Animal" button in `apps/mobile/src/cattle/CattleList.tsx` to open the modal.
   - On successful save, refresh cache and update the herd list immediately.
4. **Translations**:
   - English and Bengali parity in `apps/mobile/src/i18n/messages.ts`.
5. **Testing & Quality**:
   - Unit and component tests for modal navigation and submission.
   - Zero ESLint and TypeScript errors.
