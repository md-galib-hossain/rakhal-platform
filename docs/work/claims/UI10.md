# UI10: Modal height capping, consistent notification sheet layout, and input clipping fix

## Completed Objectives
1. **Modal Height Capping**: Added `heightFraction?: number` and `maxHeightFraction?: number` to `SheetModal` to enforce consistent maximum heights so modals do not stretch past 75-80% of window height into the camera notch/status bar.
2. **Fixed Height across Notification Tabs**: Configured `NotificationSheet` with `heightFraction={0.78}` so Inbox, Upcoming, and New composer all maintain the exact same height, preventing abrupt jumping or layout shifting between empty states and filled tabs.
3. **Fixed Pinned Header & Segmented Tabs**: Added `scrollable={false}` to `SheetModal` to allow sheets to host pinned Header and Tabs at the top with a scrollable inner body (`flex: 1`). The title, settings slider button, close `✕` button, and tabs never scroll off-screen when typing into form fields or scrolling.
4. **Animal Picker Converted to Bottom Sheet**: Converted full-screen 100% `<Modal>` in `NewTab.tsx` to `<SheetModal heightFraction={0.75} scrollable={false}>`. The title and close button now comfortably sit at 75% height within easy thumb reach.
5. **Fixed Input Border Clipping**: Added `paddingHorizontal: 4` to form container and `marginHorizontal: 2` to `TextField.tsx` plus `borderColor: focused ? colors.primary : borderColor`, ensuring focus rings have ample buffer space and are never clipped by container boundaries.
