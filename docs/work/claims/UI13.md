# UI13: Animal Profile Consistency: Button Text (+ Weight) & Predictable Section Heights

## Objectives
1. Fix button label: Change "+ Weigh" to "+ Weight" on Growth & Weight card (English and Bengali parity).
2. Predictable, Consistent Section Heights:
   - Eliminate mixture of erratic section heights across animals.
   - For sections like "Next up & Reminders", "Growth & Weight", "Health", "Milk Production", establish consistent, well-proportioned dimensions / minHeights.
   - When an animal has no reminders or no records, display a structured empty state inside the well-fit section rather than collapsing or having mismatched heights.
3. Apply consistent predictability across all workspace sections/tabs in the animal profile.
4. Verify on live emulator across animals (e.g. Lokkhi with data vs an animal without data like COW-DEV-001 / Shundori).
