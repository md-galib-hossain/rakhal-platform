## Finding: pnpm 10 ignored build scripts (`sharp`, `@swc/core`, `@parcel/watcher`, `unrs-resolver`)

Not changed. Evidence: on the clean clone `sharp` loads and reports libvips 8.17.3 even though its install script
was ignored, because the prebuilt binary ships as an optional dependency (`@img/sharp-win32-x64`; the Linux build
uses `@img/sharp-linux-x64`). Build and tests pass without the scripts. So the practical risk is low, but it is a
different install behaviour from the frontend repo's pnpm 11, so for the owner:

- Option A (recommended): leave as is and watch the first CI run on Linux.
- Option B: add `"pnpm": { "onlyBuiltDependencies": ["sharp", "@swc/core", "@parcel/watcher", "unrs-resolver"] }`
  to the root `package.json`. This changes what runs at install time on the VPS and in CI, so it is an owner
  decision, not applied here.
